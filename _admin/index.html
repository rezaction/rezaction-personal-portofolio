Hubungkan ke repo GitHub situsmu. Semua perubahan disimpan sebagai commit, lalu Cloudflare otomatis deploy.

Cara membuat token (sekali saja)
  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pilih repo situs ini saja.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Expiration: pilih sesukamu, lalu Generate dan salin token (diawali github_pat_).
Token hanya disimpan di browser perangkat ini.
