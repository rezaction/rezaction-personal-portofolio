WEBSITE REZA PAMVNGKAS

Buka index.html di browser (butuh internet untuk Google Fonts).
Folder assets/ berisi foto header (header.png) dan foto easter egg (easter-egg.png). Ganti dengan nama file yang sama kalau mau update foto.

LINK YANG MASIH KOSONG
Buka index.html di text editor, cari  href="#"  lalu isi dengan URL aslinya:
1. Nama proyek ADSPACE
2. Nama proyek VERA
3. Nama proyek WORKKIT SERVICE
4. CV Dwimanunggal Indonesia
5. PT Dwimanunggal Indonesia Sejahtera
6. Dua tombol Download CV (isi dengan path file CV, misalnya cv.pdf)
